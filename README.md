# Jack Gummy 🎃

ハロウィンの夜の、ぷにぷにグミのおもちゃです。
カボチャのグミを動かして、色のちがう仲間にぶつけて「味」を集めていくと、自分のグミがだんだん黒くなって、最後に笑って星になります。集めた味の割合で、世界にひとつの「不思議な味のグミ」が完成します。

**遊ぶ:** https://（GitHubのユーザー名）.github.io/jack-gummy/

## 遊び方

- グミをつまんで動かして、色のちがうグミにそっとぶつけます。
- 赤はいちご、青はラムネ、黄はレモン。ぶつけると味をもらえます。
- 味を集めるほど、自分のグミは色が変わって重くなります。
- 黒く染まると、ニコッと笑って、星になって弾けます。
- 完成カードに、味の名前と割合が出ます。右上のボタンで効果音のオン・オフ、はじめからやり直しができます。

## 動作環境

- スマホのブラウザ(縦画面)を想定しています。パソコンのブラウザでも遊べます。
- 効果音は、端末がマナーモードだと鳴らないことがあります。
- 文字のフォントはGoogle Fontsから読み込みます。読み込めない環境では、端末の標準フォントで表示されます。
